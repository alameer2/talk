# 🎙️ محول ملفات الترجمة SRT إلى كلام عربي

مشروع بايثون متقدم يقوم بتحويل ملفات الترجمة SRT إلى كلام عربي مع الحفاظ على التوقيت الدقيق لكل سطر ترجمة. المشروع مجاني تماماً ولا يعتمد على أي مفاتيح تفعيل مدفوعة.

## ✨ المميزات

### الميزات الأساسية
- ✅ **قراءة وتحليل ملفات SRT** - تحليل كامل لملفات الترجمة واستخراج التوقيت والنص لكل سطر
- ✅ **تحويل النص إلى كلام** - باستخدام مكتبة gTTS المجانية (يحتاج إنترنت) أو pyttsx3 (يعمل بدون إنترنت)
- ✅ **الحفاظ على التزامن** - تزامن دقيق بين الصوت والفيديو
- ✅ **معالجة ذكية** - معالجة علامات الترقيم العربية (الفواصل، النقاط، علامات التعجب والاستفهام)
- ✅ **تحكم كامل** - في سرعة الكلام وجودة الصوت
- ✅ **خيارات متعددة** - إنشاء ملف صوتي واحد أو ملفات منفصلة لكل سطر
- ✅ **رفع مرن** - رفع الملفات مباشرة أو من مجلد `upload`
- ✅ **شريط تقدم** - متابعة حية لعملية التحويل

### التقنيات المستخدمة
- **Streamlit** - واجهة مستخدم تفاعلية وجميلة
- **pysrt** - تحليل ومعالجة ملفات SRT
- **gTTS** - تحويل النص إلى كلام عبر Google (مجاني)
- **pyttsx3** - تحويل النص إلى كلام محلياً (بدون إنترنت)
- **pydub** - معالجة ومعايرة الملفات الصوتية
- **arabic-reshaper** و **python-bidi** - معالجة صحيحة للنصوص العربية

## 📋 المتطلبات

- Python 3.11 أو أحدث
- اتصال بالإنترنت (لاستخدام gTTS)

## 🚀 التثبيت والتشغيل

### الطريقة 1: التشغيل على Replit

1. انسخ المشروع إلى حسابك على Replit
2. انقر على زر "Run" - سيتم تثبيت جميع المكتبات تلقائياً
3. سيفتح التطبيق في نافذة جديدة تلقائياً

### الطريقة 2: التشغيل المحلي

1. استنسخ المشروع:
```bash
git clone https://github.com/your-username/srt-to-arabic-speech.git
cd srt-to-arabic-speech
```

2. ثبت المكتبات المطلوبة:
```bash
pip install -r requirements.txt
```
أو باستخدام `uv`:
```bash
uv pip install -e .
```

3. شغل التطبيق:
```bash
streamlit run app.py --server.port 5000
```

4. افتح المتصفح على العنوان: `http://localhost:5000`

## 📖 كيفية الاستخدام

### 1. رفع ملف الترجمة

اختر إحدى الطريقتين:
- **رفع مباشر**: اسحب ملف SRT وأفلته في المنطقة المخصصة
- **من مجلد upload**: ضع ملف SRT في مجلد `upload` واختره من القائمة

### 2. ضبط الإعدادات

في الشريط الجانبي، يمكنك ضبط:

#### 🔊 إعدادات الصوت
- **محرك التحويل**: اختر بين gTTS (يحتاج إنترنت، جودة أفضل) أو pyttsx3 (يعمل بدون إنترنت)
- **سرعة الكلام**: من 0.5 (بطيء) إلى 2.0 (سريع)

#### 📁 إعدادات الإخراج
- **نوع الإخراج**: 
  - ملف صوتي واحد متكامل (جميع السطور في ملف واحد)
  - ملفات منفصلة لكل سطر (ملف لكل سطر ترجمة)
- **جودة الصوت**: عالية (192 kbps) / متوسطة (128 kbps) / منخفضة (64 kbps)

#### 🔧 إعدادات متقدمة
- **مدة التوقف بين الجمل**: من 0 إلى 3 ثواني
- **معالجة علامات الترقيم**: تفعيل/تعطيل التوقف الطبيعي عند علامات الترقيم

### 3. بدء التحويل

1. بعد رفع الملف، ستظهر معلومات عن الملف (عدد السطور، المدة الإجمالية، عدد الأحرف)
2. اضغط على زر **"🚀 بدء التحويل إلى كلام"**
3. انتظر حتى تكتمل العملية (سيظهر شريط تقدم)
4. حمل الملف الناتج

## 🔧 الوظائف التقنية

### معالج SRT (`srt_processor.py`)
- قراءة وتحليل ملفات SRT
- استخراج التوقيت والنص لكل سطر
- تنظيف النصوص من علامات HTML والتنسيقات
- دعم ترميزات متعددة (UTF-8, CP1256, ISO-8859-1)
- إحصائيات مفصلة عن الملف

### محرك TTS (`tts_engine.py`)
- دعم محركين: gTTS و pyttsx3
- تحويل تلقائي للمحرك الاحتياطي عند الفشل
- التحكم في سرعة الكلام
- دعم كامل للغة العربية

### معالج الصوت (`audio_utils.py`)
- إنشاء مقاطع صوتية مع توقيت دقيق
- دمج المقاطع الصوتية
- تحويل صيغ الصوت
- ضغط الملفات في أرشيف ZIP
- تعديل مستوى الصوت
- إزالة الصمت

### معالج النصوص (`text_processor.py`)
- معالجة شاملة للنصوص العربية
- تشكيل النصوص العربية (RTL)
- معالجة علامات الترقيم
- تحويل الأرقام
- تنظيف النصوص
- تقسيم النصوص الطويلة

- **تعليم اللغات**: مساعدة في تعلم اللغة العربية
- **إمكانية الوصول**: مساعدة الأشخاص ضعاف البصر

## ⚠️ ملاحظات مهمة

- **gTTS يحتاج إنترنت**: للحصول على أفضل جودة، تأكد من اتصالك بالإنترنت
- **pyttsx3 للاستخدام بدون إنترنت**: الجودة أقل لكنه يعمل دون اتصال
- **المعالجة قد تستغرق وقتاً**: حسب حجم الملف وعدد السطور
- **الملفات المؤقتة**: يتم حذفها تلقائياً بعد كل عملية

## 🐛 حل المشاكل الشائعة

### المشكلة: خطأ في قراءة الملف
**الحل**: تأكد من أن الملف بصيغة SRT صحيحة وبترميز UTF-8

### المشكلة: جودة الصوت سيئة
**الحل**: 
- استخدم gTTS بدلاً من pyttsx3
- زد جودة الصوت إلى "عالية"
- قلل سرعة الكلام

### المشكلة: التطبيق بطيء
**الحل**:
- قلل جودة الصوت إلى "متوسطة"
- استخدم "ملفات منفصلة" بدلاً من "ملف واحد"

### المشكلة: الصوت غير متزامن
**الحل**: تأكد من أن ملف SRT يحتوي على توقيت صحيح
